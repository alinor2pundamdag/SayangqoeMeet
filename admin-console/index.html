Scope and safety

This console exposes read-only overview and audit-history operations only. User lookup, reports/moderation, suspension, and live call/media review remain disabled until a documented data model, explicit authorization rules, participant notice, retention policy, and acceptance tests are approved. No hidden recording or message-content inspection is performed.

Never enter a service-role key, Firebase service-account credential, or other privileged secret. Only a public Supabase publishable key belongs in this browser client.
